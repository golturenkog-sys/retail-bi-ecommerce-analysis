# Retail-BI-ecommerce-analysis
North Star E-Commerce — Retail BI Analysis

Project Overview

An end-to-end Business Intelligence project analysing e-commerce sales data using SQL Server and Power BI. The goal was to evaluate sales performance, identify trends and uncover opportunities to improve business performance.

Tools Used

* SQL Server: Data preparation, SQL queries and sales analysis.
* Power BI: Interactive dashboard and KPI visualisation.

Key Business Insights

* Market performance: Ireland generated €2.58M in net sales, approximately 46% of total sales.
* Seasonality: December recorded the highest monthly net sales at €736.8K.
* Product performance: Monitors had an 89.88% increase in average monthly sales during November–December compared with January–October.
* Profitability: Desk Setup achieved the highest gross margin at 59.56%, while PC Accessories generated the highest gross profit at €964.6K.

Dashboard

An executive dashboard tracking revenue, orders, units sold, gross profit, gross margin and average order value.

Business Recommendations

* Investigate the factors behind Ireland’s higher order volume.
* Plan inventory around year-end sales patterns.
* Review pricing and costs in lower-margin product categories.
* Explore opportunities to grow higher-margin categories.

Project Status

Portfolio project — analysis and dashboard development completed. Further documentation and project files will be added.
